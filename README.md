# Dexality

!["Иконка"](https://github.com/gemnibro-ux/Pixel-Flash/blob/main/icon.png)

_Спойлер: Эмулятор находится в разработке. Если заметите баг то предупредите!_

Dexality (бывший Pixel Flash) — Это небольшой эмулятор, написаный на Python, созданный для тестирования всяких функции и для эксперементов. Он написан спецально для иследователей, энтузиастов и любетелей кастомных эмуляторов. В нем базовая работа ячеек и регистров и удобные функции. В нем находится 10 различных функции. Таких как cell, halt, move, add и многих других, мы обсудим внизу! Так что, прочитайте **ВНИМАТЕЛЬНО** весь текст...

## Возможности моего эмулятора 💻

- Самый, самый простой дизайн
- Можно очищать консоль
- Ошибки в эмуляторе (как же без него)
- Безопасность! Он не влияет на ядро

## Функции

1. PASTE РЕГИСТР ЗНАЧЕНИЕ:
- На нём можно изменить значение регистра
- Так же можно изменить значение через другие переменные

2. ADD РЕГИСТР1 РЕГИСТР2:
- Это то же самое, но там прибавлять

3. REG РЕГИСТР
- Эта функция печатает значение определённого регистра
- Есть фишка: REG __REGS. Он печатает все регистры

4. MSG СТРОКА
- На нём можно писать слова. Пример: MSG: Hi, bro!

5. MAKE РЕГИСТР ЗНАЧЕНИЕ
- Создаёт регистры собственного значение

6. DEL РЕГИСТР
- Эта функция удаляет определённый регистр

7. MOVE РЕГИСТР1 РЕГИСТР2
- Функция, которая перемешивает второй регистр с первым

8. REMOVE РЕГИСТР
-  Функция, которая возращает старое значение определённого регистра изменившиеся через MOVE

9. HALT
- Эта функция просто останавливает весь код

10. CLEAR РЕГИСТР
- Она очищает определённый регистр до полного нуля
- Фишка: CLEAR __REGS. Очищает все регистры до полного нуля.

## Примерный код
1. Чтобы всё заработало скачайте Python и библеотеку Pillow. Рекомендуется скачать версию 3.12 или выше.
2. Вставте этот код снизу (Необъезательно).

Пример кода:
```PF
MSG Hello, World!
PASTE R1 120
PASTE R2 220
PASTE R3 320
PASTE R4 420
PASTE R5 520
REG __REGS__
```
3. Запустите код и наслаждайтесь!<br><br><br>
