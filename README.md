# Dexality

!["Иконка"](https://github.com/gemnibro-ux/Dexality/blob/main/icon.png)

_Спойлер: Эмулятор находится в разработке. Если заметите баг то предупредите!_

Dexality (бывший Pixel Flash) — Это небольшой эмулятор, написаный на Python, созданный для тестирования всяких функции и для эксперементов. Он написан спецально для иследователей, энтузиастов и любетелей кастомных эмуляторов. В нем базовая работа ячеек и регистров и удобные функции. В нем находится 10 различных функции. Таких как cell, halt, move, add и многих других, мы обсудим внизу! Так что, прочитайте **ВНИМАТЕЛЬНО** весь текст...

## Возможности моего эмулятора 💻

- Самый, самый простой дизайн
- Можно очищать консоль
- Ошибки в эмуляторе (как же без него)
- Безопасность! Он не влияет на ядро

## Главные функции

1. move РЕГИСТР ЗНАЧЕНИЯ_ИЛИ_РЕГИСТР:
   !["НОГИ ПТИЧИЙ ПОМЕТ"](https://github.com/gemnibro-ux/Dexality/blob/main/fascialnie_prostranstva_stopi-1230883476.jpg)
- Функция, которая перемешивает первый регистр со голым значениям
- Также она может двигать регистр к другому регистру

2. add РЕГИСТР1 РЕГИСТР2:
- Эта команда прибавляет данные регистра к другому регистру

3. msg ТИП ОБЪЕКТ
- Эта функция ищет значения обЪекта по через определения его типа, по примеру: msg cell hi

4. cell ЯЧЕЙКА ЗНАЧЕНИЕ
- Создаёт в памяти временную ячейку данных со указаным значением

5. halt
   !["Х"](https://github.com/gemnibro-ux/Dexality/blob/main/znak-stop-i-stop-liniia-1-805676338.webp)
- Эта функция останавливает терминал

Другие функции находится в документации Dexality
